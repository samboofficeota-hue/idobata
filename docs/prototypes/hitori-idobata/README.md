## 0. ひとことで

- 1つの HTML ファイル（`index.html`）だけで動く。下準備からドキュメントまで、17の段階を一通り試せる
- AIの役（ファシリテーター、書記、点検係、資料係、整理係、AI参加者、編集者）は、**Claude で動かすか、台本（決まった返事）で動かすか**を選べる
- 〔デモ〕を押すと、例文を順に話し、ボタンも自動で押して、最後まで進む
- お題と関連資料は、**試作用の架空のもの**（みどり市の放課後の居場所）。数字も架空

## 3. 確かめられること

| 確かめどころ | 試し方 |
|---|---|
| ボードと会話の並べ方 | 右上の設定で「上下に並べる」「タブで切り替える」を比べる |
| 付箋が返事より遅れて貼られる「ずれ」 | 台本のとき、設定で書記の遅れを変える |
| AIの動き | 右上の線の印。どの役が、何をきっかけに、何秒で、何をしたか。プログラムが捨てた出力も残る |
| 点検の見せ方 | 課題整理・ゴール設定で、案のカードに「誰が ✓」「なぜ ？」が付く |
| 資料係 | 課題整理で「市全体でどれくらい？」と聞くと、ファシリテーターが出典つきで事実を示す。ボードの「資料から」に並ぶ |
| AI参加者 | 自分のアイデアを出したあとに〔ほかの人のアイデアも聞く〕 |

## 4. できないこと

- 本当の音声入力（押すと例文が入る。claude.ai のページからはマイクが使えないため）
- ボードの〔戻す〕（前の状態に戻す）、みんなの声、効果の見通し
- 壁やホストに届ける操作（ドキュメントのコピーと、ファイルへの保存まで）
