# いどばたの声のプロフィール

> 作成日：2026-10-19 ／ ステータス：**第1版を実装。本物のAIではまだ動かしていない**
>
> 付ける項目は、試しながら増やす・減らす・変える前提。

いどばたが利用者の書き込みから抽出する「課題」「解決策」に、**誰の立場から・何に基づいて・なぜ・何を大事にして**言った声なのかを付け足す。会議室のAIキャラが「別の場では、こういう立場の人が、こういう理由で〜と言っていました」と、ぶれずに話すための材料にする。

---

## 1. いどばた本体への影響

**本体の動きは変わらない。**

| | |
|---|---|
| 本体のデータ | `Problem` / `Solution` / `ChatThread` / `ImportedItem` は**読むだけ**。書き込むのは新しいコレクション `voiceprofiles` だけ |
| 本体の処理 | 抽出・紐づけ・問いの生成・分析は、一切変えていない |
| 動くとき | 環境変数 `VOICE_PROFILE_SCHEDULE` を設定したとき、または手で `scripts/profileVoices.mjs` を実行したときだけ。**既定では動かない** |
| 共有するもの | **OpenAI の利用枠**（1分あたり500リクエスト／50万トークン）。授業のない時間帯に動かす |

---

## 2. 付ける項目（第1版）

| 項目 | 中身 | 値 |
|---|---|---|
| `stance` 立場 | お題との関わり方 | 当事者／周りの人／支える立場／決める・運営する立場／外から見ている人／不明 |
| `evidence` 根拠 | 何に基づく声か | 自分の経験／見聞き／考え・推測／不明 |
| `reason` 理由 | なぜそう思うか | 80字まで。書かれていなければ空 |
| `values` 大事にしていること | 0〜3個 | 安全、健康、費用、手間、便利さ、公平、自由、つながり、環境、学び、将来、伝統 |
| `concern` 懸念 | 解決策だけ。その案への心配 | 80字まで。書かれていなければ空 |
| `answersProblemIds` 対応する課題 | 解決策だけ。同じ書き込みの中の課題のうち、この解決策が答えているもの | 課題のID |

- 値の候補は `idea-discussion/backend/services/voiceProfile/labels.js` にまとめてある。**ここを直せば、項目を増やす・減らす・変えることができる**
- 候補や指示文を変えたら `PROFILE_SCHEMA_VERSION` を上げる。古いプロフィールは、次に動いたときに作り直される
- 読み取れないものは、推測で埋めずに「不明」や空にする
- 年齢・性別・国籍・病気・信条など、**人そのものの属性は付けない**。個人名・住所・連絡先も書かない

## 3. しくみ

```
Problem / Solution（本体）──読む──▶ 作り直しが必要な声を探す ──▶ 抽出元ごとにAIを1回呼ぶ ──▶ voiceprofiles
ChatThread（利用者の発言だけ）／ImportedItem ──読む──┘
```

- **作り直す声**：プロフィールがまだない声、**文が書き換わった声**（文のハッシュで判定）、項目の版が古い声
- **まとめて読む単位**：抽出元（対話1つ、または取り込んだ意見1件）。同じ書き込みから出た課題と解決策を一緒に読むので、「どの解決策がどの課題に答えているか」を付けられる
- **読む文章**：対話なら、利用者の発言だけ（AIの発言は読まない）。4,000字まで
  - 本体の抽出処理は、元の発言の断片（`originalSnippets`）を保存していない。そのため、元の対話を読みにいく
- **消える声**：元の課題・解決策が消えたら、プロフィールも消す
- **失敗したとき**：その抽出元を飛ばして続ける。次に動いたときにもう一度試す
- **1回に処理する量**：抽出元20件まで（`VOICE_PROFILE_LIMIT` または `--limit` で変えられる）

### 費用（見積もり・未実測）

抽出元1件につき、AIの呼び出し1回。入力は元の文章（最大4,000字）と課題・解決策で、1回あたり約2,000〜4,000トークン。`gpt-5.6-luna` なら1件0.1〜0.3円ほど。

---

## 4. 動かし方

```
# 作り直しが必要な抽出元を数えるだけ（AIは呼ばない）
railway run node scripts/profileVoices.mjs --dry-run

# テーマを絞って、10件だけ試す
railway run node scripts/profileVoices.mjs --theme <テーマのID> --limit 10

# 定期的に動かす（backend の環境変数）。例：毎日0〜6時に30分おき
VOICE_PROFILE_SCHEDULE="*/30 0-6 * * *"
VOICE_PROFILE_LIMIT=20
```

時刻は `BATCH_TIMEZONE`（既定 `Asia/Tokyo`）で数える。

## 5. 確かめたこと・まだのこと

- テスト（`tests/voiceProfile.test.js`）：値を決まった候補と長さに収めること、抽出元1つにつき呼び出しが1回であること、利用者の発言だけを読むこと、**本体のデータが1文字も変わらないこと**、何も変わっていなければAIを呼ばないこと、文が書き換わったら作り直すこと、AIが失敗しても止まらないこと、消えた声のプロフィールを消すこと
- いどばた本体のテストは、変更の前後で同じくすべて通る
- **本物のAIでは、まだ動かしていない。** 立場・根拠・理由がどれだけ正しく読み取れるかは、実際の声で試して確かめる
