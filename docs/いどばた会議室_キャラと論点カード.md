## 2. なぜ論点カードを最初に作るのか

- 肯定派・否定派が「何に対して」立つかは、論点が決まらないと決まらない。**論点が、3体の立ち位置の土台になる**
- 論点ごとに、各キャラがどちら側かを先に決めておけば、**キャラが言うことがぶれにくい。** 前回の論点だった「キャラの設定と発言の整合性」に対して、発言のたびに検査するより強く、AIの呼び出しも増えない
- 各キャラは、自分の側の材料だけを読む。**キャラごとに知識を分けられる**

## 3. 論点カード

### 3.1 中身

論点1つにつき1枚。

| 項目 | 中身 |
|---|---|
| 論点 | 「〜すべきか」の形の一文（例：共用自転車を残すべきか） |
| 肯定側の主張 | 肯定派が立つ側の考え。1〜2文 |
| 否定側の主張 | 否定派が立つ側の考え。1〜2文 |
| 決めきれない理由 | 未定派が立つところ。判断に足りない情報、両方に一理あるところ |
| 肯定側の声 | その側に立ついどばたの声（課題・解決策）と、その声のプロフィール（立場・根拠・理由・大事にしていること） |
| 否定側の声 | 同上。懸念（`concern`）の付いた声は、主にこちら |
| 未定の材料 | どの案も答えていない課題、根拠が「考え・推測」や「不明」の声、合意点 |
| 出どころ | いどばたの論点の分析（問いのID・版）、または会議室の「みんなの声の整理」 |

### 3.2 元にするもの

| 元 | 中身 | 場所 |
|---|---|---|
| いどばたの論点の分析 | 対立軸（タイトルと選択肢）、合意点、対立点 | `DebateAnalysis`（紐づいた問いの最新版） |
| 会議室のみんなの声の整理 | 対立点、合意点 | `KaigiRoom.overview` |
| いどばたの声とプロフィール | 課題・解決策と、立場・根拠・理由・懸念・対応する課題 | `Problem` / `Solution`、`VoiceProfile` |
| ホストの資料 | 規約・議事録など | 資料の断片（[`いどばた会議室_AIが読む情報.md`](./いどばた会議室_AIが読む情報.md)） |

### 3.3 処理する順番

```
① お題をつくるとき（1回）
   問いを紐づける → 論点の分析を読む → 論点を「〜すべきか」の形に直す
   → 声を肯定側・否定側・未定に仕分ける → 論点カード（3枚まで）

② 参加者が20分を始めるとき
   その時点のカードを、その人の20分のあいだ固定する（途中で立ち位置が変わらないように）
   いどばたの論点や声が増え・変わっていれば、カードを作り直してから固定する

③ 発言のたび
   参加者の話に一番近いカードを選ぶ
   → 話すキャラの側の声・資料だけを探して渡す
```

- ①の仕分けは、AIの呼び出しをお題1つにつき数回（論点の数だけ）。声が多ければ、声ごとではなく、論点ごとにまとめて仕分ける
- ③で探すのは、話すキャラの側の束の中だけ。全員が全部の情報を見る形にはしない
