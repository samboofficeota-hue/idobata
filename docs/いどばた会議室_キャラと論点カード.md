## 1. 決めたこと

| # | 論点 | 決定 |
|---|---|---|
| 1 | AIメンバー3体 | **ほぼ固定。肯定派・否定派・未定派**（強弱の調整はあっても、この3つは変わらない） |
| 2 | 何に対して肯定・否定するか | **論点（対立軸）に対して。** 軸ごとに、肯定派は肯定側、否定派は否定側に立つ。未定派は決めきれないところに立つ |

| 6 | 合意の持ち方 | **軸ごとに、合意と対立を持つ。**「ここまではみんな同じ（合意）、ここから分かれる（対立：肯定側／否定側）」 |
| 7 | 軸の数 | **最大3つ。** 対立が少なければ1〜2軸でよい。対立をこしらえない |
| 8 | お題に合わせた立場づくり | **肩書きだけ残す。**「否定派のケンジ（管理費を預かる理事）」のように、お題に合う肩書きを付ける |

## 2. 全体の形

```
いどばた本体（触らない）              新しく足す層                       会議室
──────────────────              ──────────────                  ──────
問いA の DebateAnalysis ─┐
問いB の DebateAnalysis ─┼─▶ テーマの3軸（ThemeAxes・版あり）─▶ お題に合わせて言い直す ─▶ 3体が立つ
問いC の DebateAnalysis ─┘        ▲                                 （お題の軸カード）
                                  │
Problem / Solution ＋ 声のプロフィール ─┘ 各軸の肯定側・否定側・未定に、元の声を結びつける
```

- 本体の問いごとの分析は、そのまま残る。テーマの3軸は、その**上に重ねる別の層**
- 声のプロフィール（[`いどばたの声のプロフィール.md`](./いどばたの声のプロフィール.md)）と同じく、本体のデータは読むだけで、書き込むのは新しいコレクションだけ

## 3. テーマの3軸（ThemeAxes）

### 3.1 中身

テーマ1つにつき1組（最大3軸）。作り直すたびに版を上げる。

| 項目 | 中身 |
|---|---|
| 軸 | 「〜すべきか」の形の一文（例：共用自転車を残すべきか） |
| 合意 | この軸で、ほぼ全員が同じ考えのところ（例：通路の安全は守るべき） |
| 肯定側の主張 | 肯定派が立つ側の考え。1〜2文 |
| 否定側の主張 | 否定派が立つ側の考え。1〜2文 |
| 決めきれない理由 | 未定派が立つところ。判断に足りない情報、両方に一理あるところ |
| 肯定側の声・否定側の声 | その側に立つ、いどばたの声（課題・解決策）のID。プロフィールで立場・根拠・理由を引ける |
| 未定の材料 | どの案も答えていない課題、根拠が「考え・推測」や「不明」の声 |
| 出どころ | 元にした問いと、その `DebateAnalysis` の版。軸ごとに、どの問いの論点から来たかをたどれるようにする |

### 3.2 作り方

1. テーマの問いごとの `DebateAnalysis`（それぞれ最新版）を集める
2. 骨組みを作る：問いごとの対立軸・合意点・対立点を読み、テーマ全体として重要な対立を**最大3軸**にまとめる。軸ごとに、合意・肯定側・否定側・決めきれない理由を書く
3. 声を結びつける：テーマの声（課題・解決策）を、プロフィールの理由・懸念・対応する課題も見ながら、各軸の肯定側・否定側・未定に仕分ける
   - 懸念（`concern`）の付いた解決策は、その案に反対する側の材料になりやすい
   - どの軸にも関係しない声は、どこにも入れない
4. 保存する（新しいコレクション。例：`ThemeAxes`）

- **まとめのまとめでずれないように**、骨組みは分析から作り、各側の中身は元の声に結びつける。会議室のキャラが話す根拠は、要約ではなく元の声
- AIの呼び出しは、骨組みに1回、声の仕分けに声の量に応じて数回（見積もり）

### 3.3 作り直し

- テーマの問いの `DebateAnalysis` の版が上がったとき、または声が一定数増えたときに作り直す
- 声のプロフィールと同じく、定期的に動かす（授業のない時間帯。既定では動かない）
- 作り直すたびに版を上げ、古い版も一定期間残す（20分の途中の参加者が、始めた時点の版を使い続けられるように）

---

## 4. 会議室での使い方

```
① お題をつくるとき
   お題に近いテーマを AI が探して紐づける（ホスト用の画面に表示し、ホストが外せる）
   → テーマの3軸のうち、お題に関係する軸を選び、お題の言葉で言い直す（お題の軸カード）

② 参加者が20分を始めるとき
   その時点の版のカードを、その人の20分のあいだ固定する

③ 発言のたび
   参加者の話に一番近い軸を選ぶ
   → 話すキャラの側（肯定側／否定側／未定）の声・資料だけを探して渡す
```

- テーマの3軸は、お題より広いことが多い。①で、**お題に関係しない軸は使わない**
- 紐づくテーマがないとき、またはお題に関係する軸がないときは、会議室の「みんなの声の整理」の対立点から、お題の軸カードを作る
