## 1. 製品の芯

> **一人ひとりが、力関係のないところで、自分の意見を最後まで作り切る。**
> **作り切った意見を並べてから、人どうしで話す。**

- 意見がまとまる前に人どうしを議論させると、力関係が生まれ、言えない人が出る。だから、意見を作る段階では人の相手をしない。相手はAIだけ
- AIは、一人で考えるだけにならないように、別の視点をぶつける役。**課題も解決策も、決めるのは本人**。AIは結論を出さない
- 製品が責任を持つのは「各自の提案がしっかりしているか」まで。会議の結論には責任を持たない

この芯に反する機能は、便利でも入れない。

## 2. 全体の層

```
┌────────────────────────────────────────────────────────────┐
│ 会議室（20分の打ち込み・壁）                                  │
│   3体のキャラ（肯定派・否定派・未定派）が、お題の軸に立って話す     │
└───────────────▲────────────────────────────────────────────┘
                │ 参加者が20分を始めた時点の版で固定して読む
┌───────────────┴────────────────────────────────────────────┐
│ 足す層（いどばた本体の上に重ねる。本体は読むだけ）                 │
│   テーマの3軸（ThemeAxes）… テーマ全体の合意・対立の軸（最大3）     │
│   声のプロフィール（VoiceProfile）… 声ごとの立場・根拠・理由など     │
└───────────────▲────────────────────────────────────────────┘
                │ 読むだけ（差分で追いかける）
┌───────────────┴────────────────────────────────────────────┐
│ いどばた本体（触らない）                                      │
│   対話・取り込んだ意見 → 課題・解決策 → 問い → 問いごとの論点分析    │
└────────────────────────────────────────────────────────────┘
```

## 3. 原則

### 原則1　いどばた本体には触らない。必要なものは「足す層」として重ねる

- 本体のデータ（課題・解決策・対話・問い・論点の分析）は**読むだけ**。書き込むのは、足す層の新しいコレクションだけ
- 本体の処理（抽出・紐づけ・問いの生成・論点の分析）は変えない
- 足す層は、**既定では動かない**。環境変数を設定したとき、または手で実行したときだけ動く
- 本体と共有するのは OpenAI の利用枠だけ。足す層の処理は、授業のない時間帯に動かす

**理由：** いどばた本体は、授業やフォーラムで実際に使われている。会議室のための変更で本体が壊れたり、ふるまいが変わったりしてはいけない。足す層なら、うまくいかなければ止めるか消すだけで元に戻せる。

### 原則2　データは増え、書き換わる前提で作る。写しを持たず、最新を参照する

- いどばたの声も、論点の分析も、どんどん増え、書き換わる。**ある時点の写しを持つと、すぐ古くなる**
- 足す層は、元の文のハッシュ（指紋）と版を持ち、**新しいもの・書き換わったものだけ**を作り直す。元が消えたら、足した情報も消す
- 本体の「作成済み」の印には頼らない（文が書き換わっても印が残り、古いままになるため）

### 原則3　最新性と一貫性の境界は「参加者が20分を始めた時点」

- 足す層はいつも最新に追いつく。一方で、**一人の参加者の20分のあいだは、始めた時点の論点（軸カード）とキャラの価値観・経験で固定する**
- 20分の途中で軸や声が入れ替わると、キャラの言うことが前後で食い違う。食い違いは、作り切った意見の土台を崩す
- 最新の情報は、次に始める参加者から読む
- ただし、**キャラの軸ごとの判断は、20分の中でも新しい情報で変わることがある**（原則4）。変わるのは判断だけで、価値観は変わらない。変わったときは理由を口に出し、記録する

> 2026-10-19 改訂：当初は「20分のあいだ立ち位置を変えない」としていた。キャラに価値観のレイヤーを入れたことで、固定するものを「論点・価値観・経験」に絞り、判断は情報で動いてよいことにした。

**理由：**「いつも最新」と「途中で言うことを変えない」は真っ向からぶつかる。仕組みで両立はできないので、境界を方針として決めた。

### 原則4　キャラは3体で固定。価値観から、軸ごとの判断が出てくる

- AIメンバーは**肯定派・否定派・未定派**の3体。強弱の調整はあっても、この3つは変わらない。名前と芯は固定で、お題に合わせて変えるのは肩書きと経験だけ
- 3体は「論点（対立軸）に対して」判断を持つ。会議室が立脚するのは、いどばた本体の問いごとの論点ではなく、**テーマ全体としての合意・対立の軸（最大3つ）**。軸ごとに、合意・賛成の主張・反対の主張・決めきれない理由を持つ
- **3軸を取ったとき、全部に反対の人はほぼいない。賛成・反対・決めかねるは、一人ひとりの中で混ざり合っている。** これが設定のキモ。肯定派・否定派・未定派は「全体としての傾き」の呼び名にすぎない。軸が2つ以上あれば、各キャラは傾きの判断が一番多く、少なくとも1つは別の判断にする
- キャラは**価値観のレイヤー**を持つ：譲れないこと・大切にしたいこと（芯。変わらない）→ 経験と、そのときの感情の積み重ね（お題ごと）→ 軸ごとの判断（そこから導く）
- **ぶれにくさは、立ち位置ではなく価値観で縛る。** 判断が変わっても、変わった理由が価値観と新しい情報で説明できれば、キャラは一貫している。説得の強さやお世辞では判断を変えない
- 軸の数は最大3つ。対立が少なければ1〜2軸でよい。**対立をこしらえない**

### 原則5　根拠は、要約ではなく元の声に結びつける

- テーマの3軸は、問いごとの分析をさらにまとめたもの。まとめのまとめは、少数の論点を落とし、意味をずらす
- だから、**軸の骨組みは分析から作り、各側の中身は元の声に結びつける**。キャラが話す根拠は元の声で、どの問い・どの声から来たかをたどれるようにする
- 声のプロフィール（立場・根拠・理由・懸念・対応する課題）が、元の声と軸をつなぐ

### 原則6　推測で埋めない。人そのものの属性は付けない

- 元の文章に書かれていないことは、推測で補わない。読み取れなければ「不明」や空にする
- AIは、資料にないことを推測で言わない。「資料にはありません」と言う
- 年齢・性別・国籍・病気・信条など、人そのものの属性は付けない。個人名・住所・連絡先も書かない。付けるのは「お題との関わり方」（当事者か、周りの人か、など）まで
- いどばたの声は、別の場（授業・政党のフォーラムなど）で集めたもの。会議室では「別の場の声」として扱い、このお題の参加者の声と混ぜない

### 原則7　天井はAIの利用枠。呼び出しを増やさず、キャッシュを効かせる

- 唯一の天井は OpenAI の利用枠（1分あたり500リクエスト／50万トークン。いどばた本体と共有）。同時に対話できる人数は約40〜55人が上限（見積もり）
- **AIが4人いても、発言1回につき呼び出しは1回。** 発言のあとに検査する呼び出しは足さない。足すなら、原価と天井への影響を先に示す
- 指示文は「**変わらない先頭 → 会話の履歴 → 毎回変わる末尾**」の順に並べる。OpenAI のキャッシュは先頭から同じ部分にしか効かないため。**探した情報や時刻など、毎回変わるものは必ず末尾に置く**
- 全員で使い回せるもの（工程3の整理、テーマの3軸、声のプロフィール）は、まとめて1回作り、使い回す
- 混んだときはエラーにせず、順番待ちにする

### 原則8　保証できないことは、保証できないと書く

- 生成AIの出力は確率的。キャラの整合性も、読み取りの正しさも、**下げられるのは外れる確率だけで、保証はできない**
- 設計書には、確かめたこと（テスト、偽のAIでの画面確認）と、確かめていないこと（本物のAIでの質・原価・キャッシュの効き）を分けて書く
- 数字には前提の種類（確定／実測／見積もり／感覚値）を付ける

### 原則9　まず必要なものを加え、試してから増やす・減らす・変える

- 最初から完成形を作らない。声のプロフィールの項目も、キャラの役割の細部も、試した結果で変える
- 変えやすいように、変わりそうなもの（値の候補、指示文の版）は1か所にまとめ、版を付ける。版を上げれば、古いものは次に作り直される
- 試すときは、テーマや件数を絞って少しずつ動かす

### 原則10　資料はAIだけが読む。ただし、内容の一部は参加者に伝わる

- ホストの資料そのものは、参加者の画面に出さない
- ただし、AIは会話の中で資料の内容に触れるので、**内容の一部は参加者に伝わる**。参加者に知られて困る資料は入れないよう、お題をつくる画面で注意する
- 資料と、そこから作ったものは、お題と同じ日に自動で削除する

## 4. 迷ったときの判断の順番

1. 製品の芯（1章）に反しないか
2. いどばた本体に触らずに済むか（原則1）
3. AIの利用枠の天井を下げないか（原則7）
4. 一人の20分の中で、キャラの言うことが食い違わないか（原則3・4）
5. 試して、戻せるか（原則9）
